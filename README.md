# Memory Game

A C++ memory matching game featuring 16 cards arranged in a 4×4 grid.

## How to Play

Find all 8 matching pairs using the fewest attempts possible.

Enter the row and column of each card, such as `13` or `1 3`.

The game tracks your attempts, displays the top three distinct scores, and allows you to play again.

## How to Compile and Run

You need a C++ compiler, such as GCC (g++).

1. Download `Yang_Memory_Game.cpp`.
2. Open a terminal in the folder containing the file.
3. Compile the program:

   `g++ Yang_Memory_Game.cpp -o MemoryGame`

4. Run the game:

   **Windows:** `.\MemoryGame.exe`

   **macOS/Linux:** `./MemoryGame`

No additional libraries or files are required.
